# FPL Command Center & Transfer Lab

A modern live dashboard and transfer planner for Fantasy Premier League (FPL).

## Features
- **Live Team Connection:** Syncs directly with FPL official API for Starting XI and Bench.
- **Stadium Grass Pitch:** Visual 2D pitch view with custom team jersey colors.
- **Smart Transfer Planner:** Filter transfer targets by club and sort by Fixture Difficulty Rating (FDR), recent form, or total points.
- **Simulation Impact:** Live preview of bank balance and form changes before making a transfer.

## How to Run
```bash
python3 server.py
```
Open `http://localhost:8080` in your browser.
